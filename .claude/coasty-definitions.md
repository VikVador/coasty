#
# Key Definitions
#

In this file, we define key terms and thresholds related to hypoxia in coastal waters.

1. **Hypoxia**: A water sample is **hypoxic** when dissolved oxygen falls below the threshold: **O_2 < 63 [µmol/kg] = 63 [mmol/m^3]**

2. **Bottom hypoxia**: Hypoxia average value between seafloor and 15 [m] above it.

3. **Bottom hypoxic layer thickness**: The depth range between the bottom and the final depth where **hypoxia** occurs.

4. **Hypoxic profile**: A profile is flagged as hypoxic if **at least one observation** within it is hypoxic

5. **Hypoxic percentage**: The fraction of times a site / region is flagged as hypoxic over its total number of samplings:

  Hypoxic [%] = (# hypoxic samples / # total samples) * 100

6. **Site**: A circular area of **radius 5 [km]** centered on a given location, we use it to count or aggregate profiles and compute hypoxic statistics
